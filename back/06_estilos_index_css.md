# 💬 Prompt 06: Estilização Global e Design System (index.css)

* **Projeto:** 01 — Chatbot de Suporte Full-Stack (AfesuTech)
* **Camada:** Camada 4 — Interface & Frontend
* **Arquivo Alvo:** `frontend/src/index.css`

---

## 🎯 Objetivo
Criar o arquivo de estilos globais com CSS moderno, variáveis para tema claro e escuro, glassmorphism, tipografia elegante, suporte a Markdown formatado e animações fluidas para o Chatbot AfesuTech.

---

## 📋 Prompt para Copiar e Executar na IA

```text
Crie o arquivo "frontend/src/index.css" com um design system completo e moderno para o Chatbot AfesuTech.

O CSS deve conter:
1. Variáveis CSS (CSS Custom Properties) com paleta harmoniosa para tema claro e tema escuro (cores primárias, gradientes roxo/índigo, fundos, superfícies em glassmorphism, bordas, sombras e cores de status).
2. Reset moderno e tipografia importada (Google Fonts: Inter / Outfit).
3. Layout responsivo com container centralizado e scrollbars customizadas e discretas.
4. Classes utilitárias e estilos para:
   - Balões de mensagem (usuário vs assistente IA com badges e avatares).
   - Estilização completa de Markdown renderizado (.markdown-body: tabelas, blocos de código com destaque, negrito, listas e citações).
   - Botões com micro-interações, hover 3D suave e efeitos de foco acessíveis.
   - Indicador de digitação (typing indicator com animação de pulso nos 3 pontinhos).
   - Animações para entrada de mensagens (slide-in / fade-in) e feedback visual (botões de Like/Dislike).
```
